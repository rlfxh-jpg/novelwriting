# 人物档案

## 主角

### 林渊
- **年龄/职业**：16岁 / 帝国边陲术法学院一年级新生
- **外貌特征**：黑发偏乱，身形略瘦，长期营养普通导致肩背不算宽阔；眼神专注时会显得格外锋利，像在拆一件复杂器物
- **性格核心**：强烈好奇、理性拆解、嘴上克制但内心不服权威
- **核心价值观**：知识应当被理解，而不应只被背诵和垄断
- **最大恐惧**：自己好不容易看见的真相再次被更大的秩序碾碎，最后活成一个只会复述模板的人
- **致命缺陷**：一旦发现结构异常就容易上头，常常低估制度风险和人心恶意
- **内心渴望**：真正理解魔法是什么，找到这个世界运行的底层规律，并证明“普通人也有资格接近真理”
- **背景故事**：
  前世是长期加班的程序员，习惯从接口、结构和冗余中寻找系统真正的运作方式。一次高强度工作后猝死，转生到魔法大陆边境小镇的普通家庭。今生父母只是靠手艺和劳作生活的平民，没有家族背景，也买不起高阶教材。林渊从小就对魔法教材里的重复段落和咒文节律有异样敏感，进入学院后，这种敏感迅速变成系统性的怀疑：为什么所有人都被要求背标准答案，却没人解释标准答案为何如此书写？
- **说话风格**：平时说话不快，喜欢先听别人讲完；一旦讲到他真正理解的东西，语速会加快，句子会变得极其精准
- **恐惧/弱项**：不擅长贵族社交、公开表演、圆滑应对教务体系；精神力并非顶级，初期施法稳定性一般
- **人物弧线**：从“只是想弄懂魔法的学生”，成长为“敢于质疑秩序、重写规则的人”
- **MBTI**：INTP

## 反派

### 鲁因·赫萨尔
- **年龄/职业**：42岁 / 学院教务监察者、议会派驻审查官
- **外貌特征**：总穿深灰长袍，袖口与领边一丝不苟；面容并不凶恶，但目光审视感极强，像随时在给人定级
- **性格核心**：秩序优先、冷静功利、厌恶不可控变量
- **核心价值观**：稳定比真理更重要，文明不能交给未经筛选的普通人
- **最大恐惧**：旧秩序在自己任内崩裂，贵族、学院、民间施法者一起失控
- **致命缺陷**：把“维护秩序”当作绝对正确，长期忽视底层苦难与知识窒息造成的后果
- **内心渴望**：证明自己是对的，证明封锁、审查和权限分层确实能让帝国活得更久
- **背景故事**：
  出身并不显赫，靠服从规则和出色执行力进入学院体制。他年轻时亲历过一次低阶施法者非法实验引发的灾难，从此坚定相信“未经授权的理解”比“未经授权的施法”更危险。对鲁因而言，林渊这类人不是天才，而是可能撬开堤坝的裂缝。
- **说话风格**：礼貌、克制、没有情绪起伏；越危险的话越会用温和语气说出来
- **恐惧/弱项**：不擅长真正的创新思考，对底层结构几乎一知半解，只擅长维护现行流程
- **人物功能**：第一卷制度性对手，代表“提错问题比犯错更危险”的学院秩序
- **MBTI**：ISTJ

## 配角

### 谢缇雅·维罗恩
- **年龄/职业**：17岁 / 本源家族旁系贵族学生
- **外貌特征**：金棕短发，制服永远笔挺，手套与法杖都保养得近乎洁癖；施法姿态标准到像教科书
- **性格核心**：骄傲、自律、敏锐、对弱者缺乏天然耐心
- **核心价值观**：秩序和才能都必须有层级，真正的力量需要门槛
- **最大恐惧**：自己赖以自豪的贵族正统知识并不“更高贵”，只是被包装得更好
- **致命缺陷**：过度相信体系训练出来的标准，对非体系内的东西先天不信任
- **内心渴望**：证明自己不是单靠家族资源，而是确实比同龄人更优秀
- **背景故事**：
  出身于掌握某一系本源调用权的家族旁支，从小接受比学院更完整的术式训练。她知道“家族版咒语”和“教学版咒语”并不完全一样，却从未真正问过为什么不同。林渊的出现，让她第一次感到有人在“读懂”她施法背后的结构，而不是只看她的天赋和家世。
- **说话风格**：措辞锋利、句子短，不喜欢解释第二遍；被戳中时会更冷而不是更大声
- **恐惧/弱项**：不擅长面对自己信仰体系的裂缝；在人际上缺少柔软度
- **人物功能**：竞争者、试探者、未来潜在盟友；也是贵族视角的入口

### 季明
- **年龄/职业**：16岁 / 平民新生，林渊的同宿舍同学
- **外貌特征**：身材结实，肤色偏深，手上总有磨损痕迹；笑起来有点憨，但精神长期紧绷
- **性格核心**：努力、现实、重感情、容易自卑
- **核心价值观**：只要够努力，总能给家里换来更好的生活
- **最大恐惧**：被学院淘汰后回到原来的生活，证明自己和家人的牺牲毫无意义
- **致命缺陷**：太习惯把自己放低，出了问题第一反应是怪自己天赋不够
- **内心渴望**：留在学院、成为正式施法者，让家里摆脱贫困
- **背景故事**：
  来自更偏远的小镇，靠全家挤出来的资源进入学院。教材残缺、魔晶配额低、练习器材也总是最差的，但他仍咬牙撑着，是最能代表“底层学徒如何被制度挤压”的角色。第一卷实训事故里，他将成为最直接的受害者之一，也因此和林渊建立最牢的早期信任。
- **说话风格**：口语直白，偶尔带点乡镇出身的粗糙感；熟悉后会主动替人打圆场
- **恐惧/弱项**：理论理解能力一般，高压下容易动作变形
- **人物功能**：底层处境代表、情感锚点、主角与现实世界的连接线

### 席恩导师
- **年龄/职业**：63岁 / 学院边缘导师，旧术式研究者
- **外貌特征**：白发稀疏，眼窝深，衣袍旧却总收拾干净；讲话前习惯先看人写过的东西
- **性格核心**：克制、谨慎、真正尊重知识，但不再轻信制度
- **核心价值观**：知识应该配得上代价，但不能永远被锁死
- **最大恐惧**：自己这一代已经失败，下一代看见问题的人也会被沉下去
- **致命缺陷**：长期被打压后变得过于保守，往往先想到代价再想到可能性
- **内心渴望**：在彻底老去之前，看到有人能把“为什么”继续问下去
- **背景故事**：
  年轻时曾参与旧术式整理项目，发现现代教学咒语存在大量解释层与封装层，却在继续深挖前被学院与议会联手压下。此后被边缘化，只能在低年级课堂与废档案堆之间消磨时日。他不是革命者，也不是英雄，但林渊的出现让他意识到：真正的后来者终于来了。
- **说话风格**：平静、含蓄、常用反问；真正关键的话只说半句，逼对方自己想明白
- **恐惧/弱项**：行动力不如年轻时，公开对抗体制的意志已经残损
- **人物功能**：导师、理论引路人、旧时代失败者的见证

### 罗莎·墨宁
- **年龄/职业**：29岁 / 学院图书馆旧档管理员
- **外貌特征**：总戴细边镜片，指尖常有墨渍；走路很轻，像总在避开别人的注意
- **性格核心**：寡言、细致、懂分寸
- **核心价值观**：记录本身就是对遗忘的反抗
- **最大恐惧**：所有旧资料最后都被删得只剩官方版本
- **致命缺陷**：过度谨慎，很多时候宁可旁观也不愿主动卷入
- **内心渴望**：有人真正读懂那些被封存的东西，而不是只把它们当灰尘
- **背景故事**：
  并非战斗型施法者，而是学院里少数真正摸过大量旧档案的人。她知道哪些资料被抽走、哪些目录被改写，也清楚某些学生如果知道太多会发生什么。第一卷里，她更多是灰色协助者，不会明着帮林渊，但可能在关键时刻“没有看见”他做了什么。
- **说话风格**：轻、短、几乎不说废话
- **人物功能**：知识封锁层面的辅助角色，为第三幕调查线提供现实通道
